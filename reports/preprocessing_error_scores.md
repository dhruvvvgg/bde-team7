# Error scores before vs after cleaning

_Generated by `scripts/15_error_scores.py`. Table: `reports/tables/table17_error_scores.csv`._

Preprocessing makes no predictions, so these are **data-quality scores**: two fixed, past-only forecasting rules are applied identically before and after cleaning and scored on the 2018-2022 readings (depth in metres; lower is better except R2). They are not model results.

- Rule 1, *same season last year*: the reading of the same season one year earlier.
- Rule 2, *seasonal mean of earlier years*: mean of all earlier same-season readings (at least 5), the pipeline's expanding baseline.

## A. Same 2,759 wells: raw values vs cleaned (main result)

Only the values differ: cleaning blanked **1,217** raw readings (the dataset authors' per-well 3-sigma rule) and changed **0** others. Our own pipeline changes no values (it only adds flags), so it adds nothing to these scores.
