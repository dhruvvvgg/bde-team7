# Where is what (Review 2 modeling)

| If asked about... | Look here |
|---|---|
| The data (final feature table, splits) | `processed/gw_features_by_state/` (Parquet by state), `processed/splits.parquet`; column rules: `docs/handoff_for_modeling.md` |
| Raw inputs | `dataset/` (CGWB groundwater CSVs from Figshare, CHIRPS monthly table) |
| Preprocessing code (pandas reference) | `src/gwstress/`, `scripts/01_...14_...`, `scripts/run_all.sh` |
| Spark version of the preprocessing | branch `spark-first-preprocessing` (`src/gwstress/spark_pipeline.py`, `docs/spark_preprocessing.md`) |
| BigQuery version and parity proof | `bigquery/` (`sql/`, `PARITY_REPORT.md`, `bigquery_section.md`) |
| Leakage protection | window frames in `src/gwstress/features.py`; tests `tests/test_features*.py`, `tests/test_data_contract.py` |
| Model inputs (sequence tensor, scalers, masking test) | `modeling/data.py` |
| TGT-M and the neural baselines | `modeling/nets.py` (TGT-M = class `TGTM2`; GRU-D = `GRUD`; variable selection = `VSN2`; gated block = `GRN`) |
| Training loop, losses, metrics, hyperparameter grids | `modeling/lib.py` |
| How each experiment is run | `modeling/run_chrono.py` (main study), `tgtm_job.py` (TGT-M jobs), `run_geo.py` (unseen states), `robust_job.py` (missing-history test), `run_pipeline.py` (runs everything) |
| Pre-registered tests | `docs/preregistration_review2.md`; code `modeling/interval_eval.py` (H1), `modeling/robust_eval.py` (H2) |
| All result numbers | `results/tables/*.csv`, `results/summary.json`; per-model configs and seeds: `results/chrono/*.json`, `results/geo/*.json` |
| Full model metrics (RMSE, MSE, MAE, MAPE, R2, NRMSE, MedAE, bias; accuracy, precision, recall, F1, specificity, AUC, MCC, kappa, balanced accuracy) | `modeling/metrics_full.py` -> `results/tables/model_metrics_*.csv` |
| Preprocessing metrics before vs after cleaning | `src/gwstress/error_metrics.py`, `scripts/15_error_scores.py` -> `reports/tables/error_metrics_*.csv`, `reports/preprocessing_error_scores.md` |
| Data for Power BI / Tableau | `results/powerbi/` |
| Notebooks to show the implementation | `notebooks/1_Implementation_Demo.ipynb`, `notebooks/2_Full_Pipeline.ipynb`; pre-run copies with saved outputs in `notebooks/prerun/` |
| Report, IEEE paper, slides | not in the repository (they are generated by `docgen`, kept in the team hand-off folder) |
